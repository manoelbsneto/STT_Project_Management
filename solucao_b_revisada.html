🔄 Comparação: MVP sem B vs MVP com B

MVP só com D (sem Copilot)

  • PM recebe Adaptive Card → preenche campos → envia
  • Tempo: ~20-30 segundos
  • Voz: via Win+H nos campos (funcional mas não ideal)
  • Consulta: abrir tab → navegar SharePoint list
  • On-demand: clicar botão → receber card → preencher
  • Setup: 4 listas SP + 10 fluxos PA
  • Experiência: funcional, produtiva

MVP com D + B (com Copilot) ⭐

  • PM fala ou digita em linguagem natural → agente confirma → executa
  • Tempo: ~10-15 segundos
  • Voz: 🎤 nativo do Copilot no Teams (1 clique)
  • Consulta: "como está o portfólio?" → resposta instantânea
  • On-demand: "atualiza X para Y" a qualquer momento
  • Setup: 4 listas SP + 10 fluxos PA + 5-8 topics Copilot
  • Experiência: premium, conversacional, voz-first

⚙️ Topics do Copilot Studio (o que configurar)

# Topic Trigger Phrases Ação
1 AtualizarStatus "atualiza projeto X", "muda status", "update" Extrai entidades → Confirma → PA grava SP
2 ConsultarPortfolio "como está o portfólio", "resumo projetos" Consulta SP → Formata resposta
3 ConsultarProjeto "status do projeto X", "me conta sobre X" Consulta SP filtrado → Drill-down
4 RegistrarRisco "novo risco", "risco no projeto X" Extrai → Confirma → PA cria item Riscos
5 RegistrarBloqueio "bloqueio", "impedimento", "projeto bloqueado" Extrai → Confirma → PA + escalar
6 PedirDecisao "decisão necessária", "preciso de aprovação" Extrai → Confirma → PA cria + card Board
7 LowConfidence (fallback quando NLU < 0.6) "Não entendi bem. Pode reformular?"
8 Greeting "oi", "olá", "bom dia" Apresentação + menu de ações
⚠️ O que o Copilot Studio NÃO substitui (ainda precisa de D):
  • SharePoint Lists continuam sendo a base de dados — Copilot lê e grava nelas
  • Power Automate continua sendo o motor de execução — Copilot chama os flows
  • Tabs no Teams e Board Views continuam para visibilidade passiva
  • Adaptive Cards continuam como fallback e para reports automáticos
✅ Recomendação revisada para seu caso:

Solução D + B como MVP — SharePoint como dados, Copilot como interface primária. Adaptive Cards como secundários. O STT funciona nativamente via Copilot. O MVP fica mais premium, mais voice-friendly, e com menor fricção para os PMs.

Prazo estimado: 4-5 semanas (1 semana a mais que D sozinha por conta dos topics do Copilot).
