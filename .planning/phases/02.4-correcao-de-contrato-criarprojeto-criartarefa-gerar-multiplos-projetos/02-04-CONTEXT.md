# Phase 2.4: CriarProjeto, CriarTarefa, Gerar_Multiplos_Projetos - Context

**Gathered:** 2026-05-11

<domain>
## Phase Boundary

This phase corrects the semantic contract around project and task creation without touching PROD.

It delivers local planning and, in the following execution phase, a local solution package that:

- Keeps project creation as a first-class capability named `CriarProjeto`.
- Makes `CriarTarefa` create only SharePoint `Tarefas` rows.
- Adds `Gerar_Multiplos_Projetos` for batch project creation with optional initial tasks.
- Uses Adaptive Cards as the primary review/confirmation experience.
- Supports multiline text and Speech-to-Text flattened input as fallback.

This phase does not authorize import, publish, deploy, live flow edits, SharePoint writes, or production cleanup.
</domain>

<decisions>
## Implementation Decisions

### Contract Split
- `CriarProjeto` writes only to `Projetos`.
- `CriarTarefa` writes only to `Tarefas`.
- `Gerar_Multiplos_Projetos` writes batch projects to `Projetos` and optional tasks to `Tarefas`.
- `CriarTarefa` must not contain project-create trigger phrases.
- `CriarProjeto` must not contain task-create trigger phrases.

### Adaptive Card First
- Adaptive Cards are Plan A for review, validation, and confirmation.
- Text multiline/STT is Plan B and must normalize to the same internal contract.
- No write is allowed from preview/validation only.
- Write requires explicit confirmation via card action or accepted string confirmation.

### Batch Contract
- Initial limit: 10 projects and 10 tasks.
- Simple batch pairing is by index: `Nome_Projeto1` -> `Tarefa1`.
- Duplicates are skipped per row, not hidden as success.
- Partial success must return per-row status.
- `ProjectID` is always generated by the system.
- `Created` is a SharePoint system field and must not be overwritten.

### Safety
- Local-only until owner approval.
- Static tests must fail if `CriarTarefa` writes to `Projetos`.
- Runtime testing only after import/publish by owner.
- No Premium, Graph direct, HTTP with Entra, Dataverse custom, or unsupported connector pattern.
</decisions>

<specifics>
## Specific Ideas

Supported multiline single-project input:

```text
Criar projeto:
NomeProjeto: Teste Projetos multilinhas
ProjectID: sistema define automaticamente
PM: Benicio De Souza Filho, Manoel
Prioridade: Alta
StatusRAG: Verde
Percentual: 0
Ativo: true

Created: 2026-05-12
Criar Tarefas:
Tarefa 1: Validar kickoff
Tarefa 2: Preparar cronograma
```

Supported batch input:

```text
Criar projetos:
Nome_Projeto1: Teste Projetos multilinhas 1
Nome_Projeto2: Teste Projetos multilinhas 2
ProjectID: sistema define automaticamente
PM: Benicio De Souza Filho, Manoel
Prioridade: Alta
StatusRAG: Verde
Percentual: 0
Ativo: true

Created: 2026-05-12
Criar Tarefas:
Tarefa1: Validar kickoff
Tarefa2: Preparar cronograma
```

Natural trigger phrases:

- `criar projeto`
- `abrir projeto`
- `criar tarefa`
- `adicionar tarefa`
- `gerar multiplos projetos`
- `criar varios projetos`
- `criar projetos em lote`
- `gerar projetos em batch`
</specifics>

<deferred>
## Deferred Ideas

- More than 10 projects/tasks per batch.
- Complex one-to-many task blocks per project.
- Full rollback orchestration across already-created rows.
- Multi-screen Adaptive Card wizard.
- Planner task creation or Planner template provisioning.
- Graph or Premium integration.
</deferred>
