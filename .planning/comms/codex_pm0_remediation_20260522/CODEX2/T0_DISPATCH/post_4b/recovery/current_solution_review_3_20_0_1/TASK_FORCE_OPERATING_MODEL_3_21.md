## Outcome Required

Produce one canonical deployable solution package, `PMO_v11_Tarefas 3.21.0.0`, with no unnecessary second deploy path and no runtime-critical dependency on the old accelerator solution.

The task force is successful only when:

1. A reproducible local package exists.
2. Every removed component has a dependency-graph reason.
3. Every kept legacy component has a known active dependency.
4. Codex #1 and Opus 4.6 sign off before Owner import.
5. Owner import + publish all customizations + bot publish passes.
6. AQ-09 smoke passes after publish.

- AQ-09 A1-A5 pass.

## Decision Rules

| Decision Type | Required Evidence |
|---|---|
| KEEP | At least one active inbound dependency or explicit Owner requirement |
| DELETE_CANDIDATE | Zero inbound package dependency and no workflowset binding |
| MIGRATE | Active dependency exists but component belongs to old runtime |
| INVESTIGATE_FIRST | Conflicting evidence, missing target, or hidden dependency risk |
| BLOCK | Exact failing file/component, command output, and proposed fix |
