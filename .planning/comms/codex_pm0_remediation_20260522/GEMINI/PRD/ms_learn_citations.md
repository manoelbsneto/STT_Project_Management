2. **Power Automate Standard Connectors and SharePoint List Integration**
   - **Topic**: Creating and updating list items in SharePoint using cloud flows with standard licensing.
   - **URL**: [https://learn.microsoft.com/en-us/connectors/sharepointonline/](https://learn.microsoft.com/en-us/connectors/sharepointonline/)
   - **Accessed**: 2026-05-22 20:15:00 BRT

3. **Microsoft Teams Card Sizing and Payload Constraints**
   - **Topic**: Card design limits and formatting inside Teams channels.
   - **URL**: [https://learn.microsoft.com/en-us/microsoftteams/platform/task-modules-and-cards/cards/cards-reference](https://learn.microsoft.com/en-us/microsoftteams/platform/task-modules-and-cards/cards/cards-reference)
