◆ Executive Summary

✗ Before (AS-IS)

  1. User asks Copilot
  2. Copilot identifies topic
  3. Copilot calls Power Automate action
  4. Flow queries/writes SharePoint
  5. Flow returns result/context to Copilot
  6. Copilot displays response
  7. RAI/XPIA layer may block after success
  • Copilot remains in operational data path
  • Internal connector context evaluated by RAI
  • Successful operations look failed to users
  • No Application Insights diagnostics

✓ After (TO-BE)

  1. User asks Copilot or uses Teams
  2. Copilot routes only, or Teams card starts directly
  3. Power Automate controls business process
  4. Adaptive Card displays/collects structured data
  5. Flow writes SharePoint and Planner
  6. Copilot receives only static acknowledgement
  • Lower XPIA exposure
  • Better UX for PMs and directors
  • Stronger audit and confirmation model
  • Planner becomes operational task destination
  • Speech-to-text preserved with review-before-write

⚠ What We Change
