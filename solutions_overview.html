🏗️ PMO com Microsoft 365

Avaliação arquitetural de 5 soluções candidatas para gestão automatizada de projetos com baixa fricção e alta visibilidade executiva

📊 Resumo Executivo

⭐ Recomendação: Solução D — SharePoint Project Status Hub + Planner Operacional

SharePoint Lists como fonte única da verdade executiva. Planner Basic apenas para tarefas. Teams como front-end. Power Automate orquestra. Adaptive Cards como mecanismo primário de entrada/saída. Zero licença adicional no MVP.

Resultado: Gerente atualiza projeto em <20 segundos via Adaptive Card. Board vê portfólio em tempo real via tab no Teams.

🅲 Solução C

Planner Padrão como Camada Principal + Teams + PA

5.5/10

Cada projeto/área tem um Planner Basic. Buckets = fases. Labels = RAG. Teams exibe Planner como aba. Power Automate tenta consolidar.

Planner BasicTeamsPower AutomateSharePoint (consolidação)

✅ Prós

  • Visual kanban familiar
  • Drag-and-drop nativo
  • Zero licença extra

❌ Contras

  • Planner NÃO é fonte da verdade para status executivo
  • Fragmentação: 1 plano por projeto = N planos isolados
  • Sem campo "Status RAG" nativo
  • Consolidação via Graph API é complexa
  • Sem histórico de status
  • Labels limitados a 25 por plano
Esforço4-6 semanas (consolidação é o gargalo)
RecomendaçãoNÃO recomendada como base de portfólio. Planner é para tarefas, não para status executivo.

🚀 Exemplo Prático — Dia Típico com Solução D

⏰
09:00 — Power Automate dispara
Busca todos os projetos ativos na lista "Projetos". Envia um Adaptive Card para cada PM no Teams.
👤
09:03 — PM João recebe card do projeto "Mobile App"
Seleciona 🟡 Amarelo, digita "Sprint atrasada 2 dias por bug crítico", marca risco "Atraso na loja". Clica Enviar. Total: 18 segundos.
⚙️
09:03 — Power Automate processa
Cria item na lista "Status Diário". Atualiza StatusRAG e UltimaAtualizacao na lista "Projetos". Cria item na lista "Riscos".
📊
10:00 — Alerta automático
PA verifica projetos sem update há 24h. Envia lembrete aos PMs que não responderam.
👔
10:30 — Diretor abre Teams
Clica na tab "Portfólio Executivo" → vê SharePoint List com Board View agrupada por StatusRAG. 3 verdes, 2 amarelos, 1 vermelho. Clica no vermelho, vê detalhes.
📋
17:00 — Resumo diário automático
PA posta Adaptive Card consolidado no canal "Board Status": 6 projetos ativos, distribuição RAG, 1 decisão pendente, 0 sem update.

✅ Prós

  • Separação clara de concerns (status ≠ tarefas)
  • Governança forte (versionamento, audit, permissões)
  • Escalável (indexação, views, archiving)
  • Zero licença adicional
  • Histórico completo de status
  • Views ricas (Board, Gallery, Calendar)

❌ Contras

  • Setup inicial requer 4 listas + 8 fluxos
  • Sem linguagem natural no MVP (vem na Fase 2)
